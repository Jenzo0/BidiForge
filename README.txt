What This Tool Does:
  BidiForge automatically detects and patches compatible Electron 
  applications using structure-based analysis to fix and optimize 
  Arabic Right-to-Left (RTL) and Bi-Directional (BiDi) text rendering 
  on Windows (including Discord, VS Code, Cursor, OpenCode, Antigravity,
  Obsidian, Slack, AI clients, and Internal Electron apps).

Quick Start:
  Simply double-click the file:
    BidiForge.bat

CLI Commands:
  - Patch all apps:   node index.js
  - Scan status:      node index.js scan
  - Clean temp files: node index.js cleanup
  - Rollback app:     node index.js rollback <app-name>
  - Run tests:        npm test
